# Live-Meeting-Summarizer-Application

### 🚀 Project Overview

This project is a Meeting AI Assistant that performs:

* Speech-to-Text transcription (Vosk)
* Optional speaker diarization
* Meeting summarization using Transformers

### ⚙️ Features

* Upload `.wav` meeting audio
* Automatic transcription
* Basic diarized output
* AI-generated summary
* Streamlit UI for interaction
